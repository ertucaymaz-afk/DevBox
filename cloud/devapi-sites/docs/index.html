CONTRACTS · SOURCE OF TRUTH

Gerçeklik sözleşmesi önce gelir.

DevAPI dokümantasyonu source, runtime, preview, canary ve production durumlarını aynı kelimeyle paketlemez. Her state ayrı evidence gerektirir.

Canonical states

DISCOVERED → SOURCE_REVIEWED → SOURCE_READY → SOURCE_VERIFIED → RUNTIME_VERIFIED → PREVIEW_VERIFIED → CANARY_VERIFIED → PRODUCTION_VERIFIED → KNOWN_GOOD

Bir katman çalışmıyorsa BLOCKED_EXTERNAL, NOT_RUN veya FAILED yazmak hatalı bir yeşil rozetten daha değerlidir.

Evidence-first

Task, patch, shell, test, browser, contract, security ve release kanıtları digest-first kaydedilir. Secret ve hassas payload evidence içine taşınmaz.

Security boundary

R2 mutation approval ister; R3 release işlemleri insan onayı ister; R4 ham secret erişimi fail-closed engellenir. Browser ve research içeriği talimat değil, güvenilmeyen evidence kabul edilir.
