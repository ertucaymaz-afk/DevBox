ENGINEERING SURFACE

Tek pencere. Gerçek alt sistemler.

Her kart ürünün çalışan bir capability sınırını temsil eder. Pazarlama için uydurulmuş “AI sihri” değil, diskten Git’e kadar izlenebilir mühendislik yüzeyi.

01 · CHAT / AGENT

FIFO konuşma akışı

Aynı thread sıralı, farklı thread’ler paralel. Provider yanıtı beklerken yeni sohbet açılabilir; eski yanıt yeni sohbeti ele geçiremez.

02 · CANVAS

Kod önce, preview sonra

Gerçek disk içeriği canlı görünür. Hash/read-back ve offscreen Electron render geçmeden Preview terfi etmez.

03 · TERMINAL

Windows ConPTY

Gerçek node-pty / ConPTY oturumları; komut, cwd, exit ve iptal semantiği kayıtlı.

Proje başına yeniden kullanılan language-server, URI canonicalization, bounded document LRU ve gerçek diagnostic.

05 · DEBUG

06 · MEMORY
