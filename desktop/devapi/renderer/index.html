READY
01

Bu program ne işe yarıyor?

DevAPI'nin ana ürün sitesi, runtime görünümü, dokümantasyonu, durum merkezi ve Agent Console'u tek Windows uygulamasında toplar. İnternet olmasa bile paketlenmiş arayüzleri açabilir.

02

Neden bazı özellikler BLOCKED?

DevAPI çalışmayan bir özelliği çalışıyormuş gibi göstermiyor. Gerçek model, veritabanı veya Vercel kimliği bağlı değilse durum açıkça beklemede kalır.

03

Sağlık kontrolü neyi doğruluyor?

Kurulu paket dosyalarının hash bütünlüğü, beş yerel yüzey, manifest politikası, özel devapi:// protokolü ve Windows kullanıcı veri dizininin yazma/okuma kabiliyeti başlangıçta denetlenir.
