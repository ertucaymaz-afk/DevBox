# DevBox v0.1.10 Canvas workspace

GIF ile yeniden üretilen `index.html` görevinin tek Hermes tool çağrısından sonra yarıda kesilmesi, global kirli Git sayacının turn başarısı gibi görünmesi ve API Gelişimi `RECOVERY_REQUIRED` durumunun belirsiz kalması bu sürüm dalının doğrulama kapsamıdır.

Başarı koşulu yalnız arayüz metni değildir. Kodlama isteğinde gerçek dosya mutasyonu, diskten hash/read-back doğrulaması, turn-local değişiklik listesi, izole HTML önizleme ve Windows CI/installer kapısı gerekir.
