# DevBox v0.1.9 — Chat + API Gelişimi runtime onarımı

Bu sürüm, kullanıcı tarafından gerçek Windows kurulumunda gözlenen iki çalışma zamanı arızasını hedefler.

## 1. Sohbet canlı event sözleşmesi

Agent progress olayları `stage`, `provider`, `model` ve `waiting` bilgilerini taşırken thread IPC sözleşmesi bunları strict Zod şemasında reddediyordu. Sonuç `unrecognized_keys` hatasıydı. v0.1.9, thread activity sözleşmesini gerçek AgentProgressEvent yüküyle hizalar; event metadata'sı kaybolmadan renderer'a ulaşır.

## 2. API Gelişimi / Şimdi çalıştır — Codex Windows keşfi

v0.1.8 yalnız açık `DEVBOX_CODEX_EXECUTABLE` veya eski global npm vendor düzenini arıyordu. Güncel OpenAI Codex standalone Windows kurulumu ise `CODEX_HOME/packages/standalone/current` ve `%LOCALAPPDATA%/Programs/OpenAI/Codex/bin` düzenlerini kullanır. v0.1.9 bu gerçek kurulum düzenlerini ve doğrudan PATH adaylarını da arar.

## Gerçeklik sözleşmesi

- Simülasyon/demo/fake/sahte başarı yoktur.
- `Şimdi çalıştır` gerçek provider erişimi, gerçek workspace mutasyonu, gerçek doğrulama ve gerçek Git commit olmadan görevi PASS saymaz.
- Codex workspace-write host probunu geçmezse read-only model çıktısından doğrulanmış unified patch alınır; `git apply --check` geçmeden çalışma alanına uygulanmaz.
- Durdur, aktif süreç ağacını iptal eder.
- Harici erişim veya recovery engeli varsa sistem bunu başarı gibi göstermeden fail-closed durur.
