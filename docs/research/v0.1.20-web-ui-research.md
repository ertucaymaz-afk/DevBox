# DevBox v0.1.20 web/UI araştırma kaydı

Bu kayıt, DevBox ürün sitesi ve DevAPI Cloud Control modernizasyonunda incelenen açık kaynak tasarım/animasyon kaynaklarını ve alınan mimari kararları belgeler.

## Motion

- Kaynak: https://github.com/motiondivision/motion
- Lisans: MIT
- İncelenen desenler: hybrid JS/browser animation engine, spring/layout/scroll-linked hareket, TypeScript ve tree-shakable paketleme.
- Karar: v0.1.20 statik Vercel yüzeylerinde birkaç reveal/orbit hareketi için yeni runtime dependency eklenmedi. Native CSS/Web Animations/IntersectionObserver yeterli. Daha karmaşık drag/layout choreography gerektiğinde Motion tercih edilebilir.

## Anime.js

- Kaynak: https://github.com/juliangarnier/anime
- Lisans: MIT
- İncelenen desenler: DOM/SVG/CSS timeline, lightweight animation API, WAAPI/engine yaklaşımı.
- Karar: mevcut ürün sitesinde harici runtime gerekmiyor; SVG/DOM animasyonları native katmanda tutuldu. Dependency ancak gerçek kullanım alanı oluşursa eklenmeli.

## shadcn/ui

- Kaynak: https://github.com/shadcn-ui/ui
- Lisans: MIT
- İncelenen desenler: accessible composable component surfaces, dashboard spacing, focus/interaction states, açık kaynak/open-code dağıtım yaklaşımı.
- Karar: siteler React/Tailwind'e taşınmadı. Tasarım dili; card hierarchy, focus-visible, dense control-plane yüzeyi ve erişilebilir responsive düzen olarak uyarlandı.

## Vercel staged promotion

- Resmi dokümantasyon: https://vercel.com/docs/cli/deploying-from-cli
- Karar: production alias doğrudan kaynak üzerine taşınmayacak. Önce immutable/staged production deployment, smoke/canary ve ancak PASS ise canonical promotion yapılacak.
- Strict control-command FIFO, Vercel Queues'a taşınmayacak. At-least-once teslim modeli nedeniyle command hattında mevcut sequence + ACK + idempotency sözleşmesi korunacak. Queue yalnız telemetry/evidence fan-out gibi non-control işlerde değerlendirilebilir.

## Tasarım ilkeleri

1. Fake telemetry ve örnek seviye/score yok.
2. Live endpoint cevap vermezse `— / UNAVAILABLE`.
3. `prefers-reduced-motion` desteklenir.
4. Gizli sekmede polling durur.
5. Harici CDN/script olmadan first paint çalışır.
6. CSP, frame deny, permissions policy ve referrer policy aktif.
7. Mobil/desktop layout aynı bilgi mimarisini korur.
8. Gereksiz package eklemek “premium” sayılmaz; supply-chain ve payload bütçesi ayrı gate'tir.
