# v0.1.20 release policy

Source gate ile production gate ayrıdır. `pnpm verify` source gerçekliğini doğrular. `pnpm production:verify` yalnız gerçek Vercel deployment, canonical URL, health/public-state canary, desktop command ACK canary, runtime error scan ve rollback kanıtı mevcutsa PASS olabilir. Bu koşullar oluşmadan Windows package/release promotion final sayılmaz.
