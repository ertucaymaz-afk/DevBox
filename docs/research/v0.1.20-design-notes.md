# v0.1.20 tasarım notları

DevBox ve DevAPI web yüzeylerinde aynı ürün ailesi korunur fakat görevleri ayrıdır: DevBox public ürün vitrini alev-kırmızısı, DevAPI ise operasyon/control-plane okunabilirliği için daha soğuk cyan-mavi vurgu kullanır. İki yüzey de dış runtime animasyon kütüphanesine zorunlu bağımlı değildir; CSS, Web Animations API ve IntersectionObserver yeterli olduğu yerde native yol kullanılır. `prefers-reduced-motion`, focus görünürlüğü, responsive grid, bounded polling ve CSP release contract'ın parçasıdır.
